# 중·고 정보 기출 → 빈칸 강도 Crosswalk

기준 자료: `전공 기출_260921_105741.pdf`에 수록된 2014~2026 정보·컴퓨터 임용 기출.

## 판정 원칙

1. 최근 2022 개정 직접 출제(2024~2026)를 최우선으로 반영한다.
2. 2014~2023에서 반복된 교육과정 출제 형식(원문 용어, 영역/내용체계, 성취기준, 교수·학습·평가)을 보조 근거로 사용한다.
3. 기출에서 공식 문구를 직접 답으로 요구한 경우, 기존 `키워드 +@` 범주라도 해당 답안 단위는 핵심 빈칸으로 승격할 수 있다.
4. 이미 `지식·이해 / 과정·기능 / 성취기준`의 정확 암기 단계에서 회수되는 항목은 중복 승격하지 않는다.
5. 기출이 인용한 문장이 corpus에 보이지 않으면 먼저 공식 공개 원문으로 재검증한다. 공식 원문 누락이 확인된 경우에만 source line을 복구하고, line/gap/workload/D-day를 함께 재산정한다.

## 기출과 공개 최종안으로 재확인된 corpus 누락 — v7.8.7에서 복구 완료

이전 662문장 corpus의 과목 공통 교수⋅학습·평가에서 **12개 공식 항목**이 누락되어 있었다. 공개된 2022 개정 정보과 교육과정 최종안 및 최근 기출의 직접 인용을 교차확인하여 복구했다.

### 중학교 정보: 5개
- 교수⋅학습의 방향 (나): 학습자 맞춤형 교수⋅학습 + 디지털 역량 수준 + 추가 교육 기회
- 교수⋅학습의 방향 (다): 민주시민교육·생태전환 교육·지속가능발전 등 범교과 문제 해결
- 교수⋅학습 방법 (다): 온라인 교실·커뮤니티를 통한 학습 결손 방지
- 교수⋅학습 방법 (마): 개인차를 고려한 소집단
- 평가의 방향 (라): 단순·지엽 지식보다 문제 해결 과정을 통합적으로 관찰·평가

### 고등학교 정보: 7개
- 교수⋅학습의 방향 (나): 학습자의 흥미·다양성 및 참여를 고려한 맞춤형 교수⋅학습
- 교수⋅학습의 방향 (다): 민주시민교육·생태전환 교육·지속가능발전 등 범교과 문제 해결
- 교수⋅학습의 방향 (라): 중학교 이수 수준·학교 환경을 고려한 자율적 재구성
- 교수⋅학습 방법 (다): 문제기반학습·프로젝트 기반학습을 통한 학습자 중심 활동 경험
- 교수⋅학습 방법 (라): 온오프라인 연계와 디지털 도구 활용 경험
- 평가의 방향 (나): 지식⋅이해·과정⋅기능·가치⋅태도의 다면적·과정 중심 평가
- 평가 방법 (라): 학습 부진·느린 학습자의 참여 및 최소 성취수준 보장을 위한 평가기준 세분화

복구 뒤 중학교 정보는 **139문장**, 고등학교 정보는 **131문장**, 6과목 전체는 **674문장 / 6,327 gaps**가 되었다. 기존 line ID는 보존했고, 신규 문장에는 새 ID만 부여했다. workload와 D-day는 새 corpus 기준으로 재산정한다.
