## v1.4에서 강화한 기준

1. `(가)(나)(다)`가 장식이 아니라 서로 연결되는지 확인.
2. ‘틀린 문장을 반대로 고치기’처럼 답이 과도하게 노출되는 구성을 복수 계획·체크리스트·구체 자료 판별형으로 수정.
3. 작성 방법에서 `내용 체계 / 성취기준 / 해설 / 적용 시 고려 사항 / 교수·학습 / 평가`의 근거 층위를 명시.
4. 코드·계산·데이터·장치 역할·모델 결과 등 실제 처리 요소를 유지.
5. 4점형=1점 요소 4개, 2점형=1점 요소 2개를 고정.
6. 정답 공개 후 통합 해설 팝업 제공.

## 해설 UI

채점 후 `통합 해설 보기`를 노출한다. 실전 세트에서는 최종 제출 전에는 해설을 열 수 없다.

통합 해설에는 다음을 표시한다.
- 해결 흐름
- 1점 단위 정답과 이유
- 임용형 포인트
- 혼동 주의

기존 `근거 원문 보기`는 별도로 유지한다.
