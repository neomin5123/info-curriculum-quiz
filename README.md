# CurriLoop

2022 개정 정보과 교육과정 암기·복습·기출형 연습 PWA입니다.

## 실행
정적 웹 서버의 루트에서 `index.html`을 제공하면 됩니다. 서비스 워커가 루트 경로를 기준으로 동작하므로 파일을 직접 여는 방식보다 HTTP(S) 서버 사용을 권장합니다.

## 디렉터리 안내
- `data/curriculum/`: 교육과정 원문 기반 corpus와 별도 비교·전환 mapping (역할별 하위 폴더 분리)
- `data/questions/`: 현재 앱이 사용하는 production 문제은행
- `data/learning-aids/`: CurriLoop가 만든 암기 보조 자료(공식 원문 아님)
- `js/`: 앱과 엔진 로직
- `docs/`: 현재 적용되는 규칙·QA·구조 문서
- `tests/`: 현재 production에 대한 회귀 테스트
- `archive/`: 과거 문제은행·규칙·QA·테스트

현재 기능 버전은 **v7.7.0**입니다. 시험 직전 학습 동결판으로, `오늘 학습 시작` 중심의 단일 흐름에 **복습 75% 게이트, 2026-11-28 1차 시험 D-day 역산, 통회상 장기복습 당일 재인출**을 반영했습니다. 자동 범위 확장은 검증된 **중학교 정보에만 제한**하며, 기존 2022 공식 corpus(6과목/33영역/662문장)와 EX-001~031 문제은행 내용은 변경하지 않습니다.




## v7.7.0 시험 직전 학습 동결판

- 홈의 카드별 실행 버튼을 제거하고 **`오늘 학습 시작`**을 주 행동으로 통합했다. 앱이 복습 → 새 학습 → 잔여 복습/누적 점검 순서를 자동으로 결정한다.
- 평상시에는 오늘 복습 예산의 **75% 이상 처리**하면 예산의 25% 이하 잔여 복습을 남긴 채 새 범위를 열 수 있다. 심한 backlog와 누적 정리일은 예외로 복습을 우선한다.
- 2027학년도 중등 1차 시험일 **2026-11-28**을 기본 D-day로 사용한다. 중등 정보 자동 첫 회독 권장 마감은 **D-35(2026-10-24)**이며, 현재 진도로 권장 마감을 넘길 전망일 때 복습 부담이 안정적인 날에만 학습량 하한을 자동 보정한다.
- 홈에 `1차 시험 D-day`와 `중등 정보 첫 회독 예상일`을 표시한다.
- 통회상 장기복습은 첫 실패에서 바로 다음 날로 넘기지 않는다. **정답 확인 → 몇 문제 뒤 전체 통회상 1회 재시도 → 다시 실패하면 다음 날 이월**한다.
- v7.6.6의 중등 정보 자동 진도 안전 게이트와 v7.6.5 이하의 실제 학습일 정리·학습량 점수·미완료 세션 복원·복습 이월 로직은 유지한다.
- 교육과정 원문·2015 전환 자료·EX-001~031 production 문제은행은 변경하지 않는다.


## v7.6.6 중등 정보 자동 진도 안전 게이트

- `오늘` 플래너의 자동 새 범위는 **중학교 정보만** 인덱싱한다. 중등 정보 5영역을 마치면 자동 진도는 100%에서 종료하고 장기 복습·누적 혼합만 계속한다.
- 고등학교 정보, 인공지능 기초, 데이터 과학, 소프트웨어와 생활, 정보과학은 기존 각론 UI에서 수동 학습할 수 있지만 `오늘` 플래너가 아직 개편되지 않은 `핵심 → 정확화` 빈칸 루틴을 자동으로 시작하지 않는다.
- 홈의 진행률 표시는 `전 범위 첫 회독`이 아니라 **`중등 정보 자동 첫 회독`**으로 명확히 구분한다.
- 이전 버전에서 중등 정보 밖의 자동 세션이 이미 열려 있었다면 이를 강제로 이어가지 않는다. 작성 중 세션 상태는 별도 로컬 백업 키에 보존하고 자동 플래너에서는 안전하게 중단한다.
- 중등 정보 완료 후에도 완료된 항목은 기존 장기 복습 일정과 실제 학습일 기반 누적 혼합에 계속 참여한다.
- 교육과정 원문·2015 전환 자료·EX-001~031 production 문제은행은 변경하지 않는다.


## v7.6.5 실제 학습일 기반 누적 정리

- 정리 주기는 더 이상 첫 사용일로부터의 달력 7일을 사용하지 않는다. **실제 인출·복습이 기록된 일반 학습일 6일을 누적한 뒤, 그 다음 실제 학습일을 누적 정리일**로 잡는다.
- 앱을 열기만 하거나 며칠 쉬는 것은 카운트하지 않는다. 같은 날 여러 번 학습해도 1일로만 센다.
- 여섯 번째 일반 학습일 당일은 정상 학습일로 유지하며, 다음에 실제로 공부하는 날에 정리일이 발동한다.
- 정리일에 복습만 수행해도 그날은 전체 학습일 이력에 기록되고, 다음 6일 주기는 정리일 다음 학습일부터 새로 시작한다.
- 정리일에는 미완료 active session이 있어도 새 진도·이어 학습을 잠시 보류하고 누적 혼합 점검을 먼저 마친다. 다음 날에는 저장된 미완료 세션을 그대로 이어간다.
- 홈에는 현재 주기의 `n/6 학습일`과 다음 정리일까지 남은 실제 학습일 수를 표시한다.
- 정리일에 점검할 적격 항목이 전혀 없는 드문 경우에는 사용자가 `정리일 완료`를 눌러 주기를 명시적으로 초기화할 수 있다.



## v7.6.4 학습 부담 점수 기반 범위 배분

- 플래너의 8~22 적응 범위는 이제 `문장 수`가 아니라 **학습량 점수**다. 기본은 18점이며 속도×첫 인출 정확도 적응 규칙은 그대로 사용한다.
- 문장별 점수는 원문 길이, 자료 유형, 핵심 빈칸 수를 함께 본다. 짧은 내용 요소는 1점 안팎, 긴 성취기준 해설·고려사항은 그보다 높은 점수를 가진다.
- 중등 정보 외 과목은 아직 핵심+정확화 두 단계 빈칸을 사용하므로 normal 빈칸이 핵심 빈칸보다 유난히 많은 문장은 소폭 추가 가중한다.
- 홈에는 `새 학습량 목표 18점`을 표시하고, 오늘 범위에는 `학습량 n점 · m문장`을 함께 보여 사용자가 실제 분량과 원문 개수를 모두 확인할 수 있다.
- 영역 전체가 목표보다 5점 이내로만 초과하면 한 세션으로 끝내고, 반대로 마지막에 6점 미만의 작은 꼬리만 남게 되는 분할은 피한다.
- 첫 회독 진행률은 완료한 문장 수가 아니라 완료한 **누적 학습량 점수의 비율**을 기준으로 표시한다.
- 기존 v7.6.3 플래너 상태의 `targetLines` 8~22 값은 삭제하지 않고 같은 숫자의 학습량 점수로 자동 승계한다.

## v7.6.3 미완료 세션 이어 공부하기

- active session에 현재 단계(`원문 읽기 / 핵심 빈칸 / 실전·정확화 / 연결 확인`)를 저장한다. 단계 전환을 완료한 뒤 앱을 닫아도 다음 진입에서 그 단계부터 재개한다.
- 핵심 빈칸과 실전 통회상의 입력값·채점 상태를 active session에도 저장한다. 브라우저 세션이 바뀌어 sessionStorage 초안이 사라져도 현재 플래너 범위의 진행은 복원한다.
- 입력 단계는 복원 후 이미 채점한 항목을 유지하고 첫 미완료 입력으로 포커스를 이동한다. 통회상 묶음의 채점 여부와 구조 연습의 현재 문제도 함께 복원한다.
- 홈의 `이어 공부하기`는 같은 날 재진입과 다음 날 재진입 모두에서 작동하며 `핵심 빈칸까지 완료 · 실전 통회상부터`처럼 재개 지점을 표시한다.

- 오늘 복습에서 같은 항목을 두 번 실패하면 **오늘 할 시도는 종료**하고, 성공으로 처리하지 않은 채 다음 날 다시 예약한다. 통회상 실패와 두 번째 유사 답안도 같은 원칙으로 처리한다.
- 앱 첫 화면은 `오늘`이며 `예정 복습 → 새 범위 → 누적 혼합 → 속도`를 한 화면에서 안내한다.
- 새 범위의 `완료`는 마지막 화면까지 넘긴 것만으로 처리하지 않는다. **핵심 빈칸·통회상/정확화에서 실제 채점 시도**가 있어야 하고, 당일 지연 재인출이 남아 있으면 먼저 처리해야 한다. 다만 같은 항목의 당일 재인출을 두 번 다시 실패하면 무한 반복하지 않고 다음 날 복습으로 이월한다. 중학교 정보의 마지막 영역 세션에서는 연결형 구조 연습까지 끝내야 완료된다.
- `완료`는 복습 종료가 아니라 **장기 복습 진입**이다. 정확 인출은 기본 1→3→7→14→30→60일 간격으로 다시 나오며, 중학교 정보 통회상은 여러 날짜의 성공을 거쳐 `학습됨 → 안정화 중 → 숙달`로 올라간다.
- 하루 복습 예산은 암기가 느려져도 최소 20개 수준을 유지한다. backlog가 오늘 예산을 넘으면 **복습량을 줄이는 대신 새 학습량 목표부터 75% → 50% → 중단** 순으로 감속한다.
- 기본 새 학습량 목표는 18점이고 개인 속도·첫 인출 정확도에 따라 8~22점에서 적응한다. 끝내지 못한 범위는 다음 날 새 진도를 추가하지 않고 그대로 이어서 학습한다.
- 누적 정리일에는 단순히 새 진도를 막는 것이 아니라, 이미 학습한 항목 중 **오래 안 본 것·오답/모름 이력이 있는 것·서로 다른 영역**을 우선하여 약 6개의 누적 혼합 점검을 실제 복습 큐에 추가한다.
- 큰 영역이 여러 세션으로 나뉘어도 이전에 완료한 section과 현재 section을 합쳐 영역 전체가 끝나는 마지막 세션이면 **구조 연습을 반드시 제시**한다.
- 중학교 정보의 `지식·이해 / 과정·기능 / 성취기준`은 개별 핵심 빈칸을 장기 큐에서 제외하고 통회상 묶음으로 유지한다. 일반 문장의 여러 빈칸도 장기 복습에서는 문장 단위 일정으로 합쳐 복습 폭증을 억제한다.
- 목표량 조절 정확도는 재시도 결과로 덮어쓰지 않고 **첫 시도**만 사용한다. 중등 정보에서는 통회상 55% · 핵심 빈칸 35% · 구조 연결 10% 비중으로 종합한다.
- 학습 플래너 상태는 백업/복원에 포함한다(backup schema v10).
- **기출형 production 문제은행(EX-001~031)은 추가·수정하지 않는다.**

### v7.6.0에서 유지되는 적응 원칙

- 1일 완료 + 85% 이상 첫 인출 정확도가 반복될 때만 새 학습량 목표를 점진적으로 늘린다.
- 1일 완료라도 70% 미만이면 감속하며, 2~3일 이상 걸리면 정확도가 높을수록 감속 폭을 줄인다.
- 첫 회독 진행률, 하루 새 학습량 목표, 최근 첫 인출 정확도를 홈에서 확인한다.


## v7.5.4 핵심 빈칸 지연 재인출 + 연결 중심 구조 연습

- 중학교 정보 `핵심` 빈칸의 틀림/모름/유사 답안은 정답 확인 뒤 즉시 반복하지 않고 2~4개 다른 핵심 빈칸 뒤에 다시 꺼낸다.
- 핵심 빈칸의 당일 보수와 실전 통회상의 당일 보수 카운터를 분리한다.
- 구조 연습에서 형태만 보고 답할 수 있는 범주 판별 문제를 제거한다.
- 구조 연습은 `성취기준 ↔ 내용 요소`, `성취기준 해설 ↔ 성취기준` 연결만 사용하고 영역별 4~6문항으로 제한한다.
- **기출형 production 문제은행(EX-001~031)은 추가·수정하지 않는다.**

## v7.5.3 중등 정보 구조 연습 정리

- 구조 연습을 `출처 위치 맞히기 / 위치→원문` 중심에서 **구별·연결 연습**으로 재정의한다.
- `지식·이해 / 과정·기능 / 가치·태도` 내용 요소는 드롭다운이 아니라 선택형 칩으로 범주를 구별한다.
- 성취기준 해설은 문제에서 성취기준 코드를 숨기고, 같은 영역의 성취기준 선택지 중 직접 연결되는 성취기준을 고른 뒤 채점한다.
- 정답 코드는 채점 후에만 공개한다.
- 구조 연습은 영역별 **중복 없는 8문항 세트**로 종료되며, 세트마다 연결 문항을 최소 1개 포함한다.
- 단어만 보고 답이 드러나는 영역/출처 위치 맞히기와 실전 통회상과 중복되는 위치→원문 유형은 제거한다.
- **기출형 production 문제은행(EX-001~031)은 추가·수정하지 않는다.**

## v7.5.2 중등 정보 학습 패널 가독성 개선

- 상단 설정을 `과목 / 영역 / 출제 항목`으로 묶고, 중등 정보에서는 세 선택창이 동일 폭으로 전체 너비를 사용한다.
- `학습 방식`을 별도 구획으로 분리하고 `원문 보기 / 마스킹 / 따라치기 / 빈칸 채우기 / 구조 연습`만 배치한다.
- 중등 정보의 `핵심 / 실전`은 별도 드롭다운 대신 `빈칸 채우기` 선택 시 나타나는 세그먼트 토글로 변경한다.
- `진행`, `전체 채점`, `원문 출처`, `현재 단원 초기화`는 하단 행동 바에 분리해 학습 방식과 도구를 시각적으로 구분한다.
- 모바일에서는 선택창과 행동 바가 줄바꿈되며, 기존 학습·통회상·복습 로직은 변경하지 않는다.


## v7.5.1 중등 정보 자유 통회상 파일럿

중학교 정보에서는 난이도 등급 대신 학습 방식의 역할을 분리합니다. `원문 보기 → 마스킹 → 따라치기 → 빈칸 채우기 → 구조 연습`을 사용할 수 있고, 빈칸 채우기에서만 `핵심 / 실전`을 고릅니다.

- **핵심**: 기존의 짧은 핵심어 빈칸으로 첫 인출을 만든다.
- **실전**: `지식·이해`, `과정·기능`은 **항목 수와 슬롯을 미리 보여주지 않는 단일 입력창**에서 한 항목당 한 줄로 목록 전체를 자유회상한다. `성취기준`은 코드만 보고 문장 전체를 회상한다.
- **항목별 진단**: 목록을 통으로 쓰더라도 내부 채점은 공식 항목별로 매칭하여 누락·표기 확인·순서 이동을 구분한다.
- **같은 날 재인출**: 누락·오답 항목은 정답 확인 뒤 몇 항목 후 개별적으로 다시 묻는다.
- **다른 날 재인출**: 장기 복습은 전체 묶음으로 다시 묻는다. 최초 정확 통회상은 `학습됨`, 날짜를 건넌 재성공은 `안정화 중`, 1일→3일→7일 간격을 거친 뒤 다시 정확히 회상하면 `숙달`로 표시한다.
- **암기 강도 표시**: 지식·이해/과정·기능/성취기준=`정확 암기`, 목표/핵심 아이디어/가치·태도/해설·고려사항=`키워드 +@`, 성격/교수학습·평가 공통 원칙=`키워드`.
- **구조 연습**: 공식 문구가 어느 범주·출처 위치에 있는지, 또는 위치에서 공식 항목을 다시 복원하는 연습을 제공한다.

다른 과목은 회귀 위험을 줄이기 위해 v7.4의 기존 학습 방식을 유지하며, 중등 정보 파일럿 검증 후 순차적으로 전환합니다.
