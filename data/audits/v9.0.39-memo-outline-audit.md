## Default memo redesign
The 10 subject×area default memo overviews were changed from one-line arrow chains to narrow-panel-friendly outlines.

Rules:
1. One major step per numbered line.
2. Only subordinate concepts use indented `-` lines.
3. A specific area does not repeat its area title inside the memo body.
4. Aggregate `전체 영역` scopes use `[영역명]` section headings.
5. `중·고 정보 전체` scopes additionally distinguish school level.

Example — 고등학교 정보 / 컴퓨팅 시스템:

```text
1. 유·무선 네트워크 특성
2. 네트워크 환경 구성
3. 사물인터넷
   - 구성·동작 원리
   - 삶·사회 변화 예측
4. 피지컬 장치 선택
5. 사물인터넷 시스템 설계
```

## Safe migration
Legacy defaults are retained in code only as migration signatures.

Migration occurs only when a saved localStorage memo value is byte-for-byte identical to the old automatically generated default for that exact `subject|area` scope. It then replaces that value with the new outline.

The following are never migrated automatically:
- user-edited memo text, even if it still contains `→`
- an intentionally blank memo (`""`)
- unknown/non-CurriLoop memo keys

`개요로 초기화` intentionally replaces the current memo with the new outline after explicit confirmation, as before.
