# CurriLoop v9.0.5 — Cloze Granularity Redesign

Status: **PASS — Knowledge·Understanding area-full-list rule implemented**

## 핵심 변경
- `지식·이해`는 더 이상 개별 line cloze로 메인 학습에 출제하지 않는다.
- 학습 단위는 **학교급 × 영역**이다.
- 해당 영역의 공식 `지식·이해` 내용 요소를 **한 화면에서 전부 동시에** 묻는다.
- 각 답은 서로 달라야 하며, 입력 순서는 채점하지 않는다.
- 그룹 완료는 전 항목 정답일 때지만, 내부 mastery는 맞힌 항목별로 따로 기록할 수 있다.

## 실제 공식 항목 수
- 중학교 정보 / 컴퓨팅 시스템: **3개** — 컴퓨팅 시스템의 동작 원리 / 운영 체제의 기능 / 피지컬 컴퓨팅의 개념
- 중학교 정보 / 데이터: **3개** — 디지털 데이터 표현 방법 / 데이터 수집과 관리 / 데이터 구조화 및 해석
- 중학교 정보 / 알고리즘과 프로그래밍: **6개** — 문제 추상화 / 알고리즘 표현 방법 / 순차적인 데이터 저장 / 논리 연산 / 중첩 제어 구조 / 함수와 디버깅
- 중학교 정보 / 인공지능: **2개** — 인공지능의 개념과 특성 / 인공지능 시스템
- 중학교 정보 / 디지털 문화: **3개** — 디지털 사회와 직업 / 디지털 윤리 / 개인 정보와 저작권
- 고등학교 정보 / 컴퓨팅 시스템: **2개** — 네트워크의 구성 / 사물인터넷 시스템의 구성 및 동작 원리
- 고등학교 정보 / 데이터: **2개** — 디지털 데이터 압축과 암호화 / 빅데이터 개념과 분석
- 고등학교 정보 / 알고리즘과 프로그래밍: **7개** — 문제 분해와 모델링 / 정렬, 탐색 알고리즘 / 자료형 / 표준입출력과 파일입출력 / 다차원 데이터 활용 / 제어 구조의 응용 / 클래스와 인스턴스
- 고등학교 정보 / 인공지능: **2개** — 지능 에이전트의 역할 / 기계학습의 개념과 유형
- 고등학교 정보 / 디지털 문화: **2개** — 디지털 사회와 진로 / 정보 보호와 보안

공식 교육과정 기준 실제 범위는 **2~7개**다. 사용자가 말한 3~7개 규칙을 맞추기 위해 공식 항목을 임의로 추가하지 않고, 2개뿐인 영역은 공식 2개를 모두 묻는다.
