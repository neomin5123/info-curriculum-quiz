# CurriLoop 연습문제 출제 규칙 v1.3 — Exam Paper Structure

## 1. 최상위 목표

연습문제의 목표는 교육과정 내용을 ‘설명하는 문제’를 만드는 것이 아니라, 실제 중등 정보·컴퓨터 임용 전공 시험지에 실려도 구조적으로 어색하지 않은 문제를 만드는 것이다.

문항 수 목표는 두지 않는다. 기존 문항도 아래 기준을 통과하지 못하면 production에서 제외하고 재작성 대기 상태로 둔다.

## 2. 실제 기출형 구조

### 4점형

4점형은 원칙적으로 다음 요소 중 2개 이상을 조합한다.

- (가)·(나)·(다)와 같은 복수 자료
- 교사·예비교사·학생 대화
- 내용 체계, 성취기준, 성취기준 해설 일부
- 교수·학습 지도안 또는 평가 계획
- 코드, 의사코드, 표, 데이터, 활동지, 학생 답안
- 밑줄/기호(ⓐ 등) 또는 빈칸(㉠ 등)
- `<조건>`과 `<작성 방법>`

단순히 사례 한 문단을 읽고 교육과정 문장을 바꾸어 쓰는 형태는 4점 production으로 인정하지 않는다.

### 2점형

2점형은 답이 단답형이어도 좋다. 다만 보기·코드·표·규칙·대화 등의 자료를 실제로 읽거나 처리해야 답이 나오도록 한다.

단순 원문 빈칸 회상만으로 해결되는 문항은 총론·각론 빈칸 학습으로 보내고 연습문제 production에는 두지 않는다.

## 3. 배점의 절대 규칙

모든 채점 요소는 **정확히 1점**이다.

- 4점형 = 1점 채점 요소 4개
- 2점형 = 1점 채점 요소 2개

예시:

- 단답 4개 → 각 1점
- 단답 2개 + 한 서술 답안 안의 필수 의미 요소 2개 → 총 4개의 1점 요소
- 한 입력칸의 답안에 채점 요소가 2개 있으면 각각 독립적으로 1점씩 부분 채점한다.

‘문장 전체가 맞으면 2점, 아니면 0점’처럼 채점 근거가 뭉쳐 있는 구조는 사용하지 않는다.

## 4. 교육과정 근거 명시

문항의 `<작성 방법>`은 가능한 경우 답변 근거의 층위를 직접 지정한다.

예:

- `2022 개정 고등학교 정보과 교육과정의 ‘내용 체계’에 근거하여 ...`
- `‘성취기준 해설’에 근거하여 ...`
- `‘성취기준 적용 시 고려 사항’에 근거하여 ...`
- `‘교수·학습 방법’에 근거하여 ...`
- `‘평가의 방향/평가 방법’에 근거하여 ...`

근거 층위를 묻는 문항에서는 다른 층위의 일반론으로 정답을 대체하지 않는다.

## 5. 4점형의 인지 밀도

4점형은 최소한 두 종류의 판단을 포함한다.

예:

- 교육과정 원문 인출 + 코드 실행
- 내용 체계 판별 + 수업 계획 수정
- 알고리즘 계산 + 교수·학습 고려 사항 적용
- 학생 답안 분석 + 평가 방향 적용
- 데이터 계산 + 결과 의미 해석

네 개의 단답이 모두 같은 종류의 원문 빈칸인 문제는 4점형으로 만들지 않는다.

## 6. 답 노출 방지

다음과 같은 문제는 production에서 제외하거나 재작성한다.

- 보기에서 정답을 거의 그대로 반복하는 문제
- ‘교사가 잘못했다’라는 문장만 읽으면 반대로 쓰는 것으로 해결되는 문제
- 상식만으로 교육과정 원문을 몰라도 정답을 만들 수 있는 문제
- 실제 임용이라면 한 소문항 1점 정도에 불과한 내용을 4점으로 부풀린 문제

## 7. 전공지식과 교육과정의 결합

가능한 경우 실제 전공지식 처리 요소를 포함한다.

- 코드 빈칸 및 실행 결과
- 알고리즘 수행 과정·복잡도·비교 횟수
- 데이터 전처리 및 정규화 계산
- 연관 분석 지표 계산
- 탐색 평가함수 계산
- 자료구조 동작 결과

단, 고급 전공지식이 교육과정 문항의 핵심을 압도하지 않도록 한다.

## 8. 자동채점

`answerUnits[]`는 실제 채점 요소와 1:1로 대응한다.

- 각 `answerUnit.points = 1`
- 하나의 task가 2점이면 동일 답안 입력에 대해 1점 의미 단위 2개를 독립 채점한다.
- 조사·띄어쓰기·명백한 오타는 허용할 수 있다.
- 핵심 교육과정 행동어가 바뀌면 오답으로 본다.
- 정답 개념을 명시적으로 부정한 답안은 키워드가 포함되어도 정답 처리하지 않는다.

## 9. 기출 참조 원칙

기출에서는 **문항의 구조와 요구 인지과정**을 추출한다. 실제 기출의 문장·상황·수치를 그대로 복제하지 않는다.

특히 최근 문항에서 반복되는 구조를 우선 반영한다.

- 교육과정 자료 + 교수·학습 지도안 + 활동지
- 교사 대화 + 교육과정 빈칸 + 전공 개념 판별
- 성취기준 + 코드/알고리즘 + 평가 방법
- 내용 체계 + 성취기준 적용 시 고려 사항 + 실제 프로그램 실행

## 10. release gate

production 진입 전 다음을 모두 확인한다.

1. 공식 sourceId가 실제 존재하는가.
2. 문제의 정답이 sourceId 및 제시 자료로 유일하게 결정되는가.
3. 배점 합계와 1점 answerUnit 수가 정확히 일치하는가.
4. 4점형이 단순 빈칸 네 개로만 구성되지 않았는가.
5. 2점형도 자료 해석 없이 원문 회상만으로 풀리지 않는가.
6. 밑줄·빈칸·작성 방법이 실제로 답안 요구와 연결되는가.
7. 공식 정답 입력 시 만점을 얻는가.
8. 한 채점 요소만 누락했을 때 정확히 1점만 감점되는가.
9. 금지 오개념·명시적 부정문으로 자동채점을 우회할 수 없는가.
10. 실제 기출과 문장 복제가 아니라 구조적 유사성만 유지하는가.
