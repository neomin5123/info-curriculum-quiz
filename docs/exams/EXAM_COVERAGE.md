# Historical Exam Coverage

## 운영 원칙

Coverage는 단순히 같은 교육과정 문장을 사용했는지가 아니라 **기출이 요구한 사고 구조**가 production 문제은행에 존재하는지를 기준으로 판단한다.

상태:
- `covered`: 동일·유사한 인지 구조의 production 문항이 존재함
- `partial`: 일부 요소만 존재함
- `gap`: 유사 구조가 production에 없음

## v7.4 변화

v7.3까지 가장 명확한 구조적 공백 중 하나는 **2015와 2022 교육과정을 직접 비교하고, 단순 명칭 대응이 아니라 성취기준 해설까지 사용해 차이를 판별하는 유형**이었다.

EX-031과 `2015-2022.js` 매핑 레이어를 추가하면서 이 구조를 production에서 직접 연습할 수 있게 되었다.

## 다음 Coverage 후보

v7.4 이후에는 다음을 우선 재점검한다.

1. 교육과정 변화 비교가 프로그래밍 외 영역에서도 충분히 커버되는가
2. 인공지능 기초에서 전공지식 처리와 협력적 교수법을 동시에 요구하는 구조가 충분한가
3. 압축·암호화처럼 내용 체계 요소에서 실제 알고리즘 처리로 넘어가는 구조가 반복 편향 없이 커버되는가
4. 생성 문항이 교육과정 원문 회상에 과도하게 의존하지 않고 실제 자료 처리·판단을 포함하는가
