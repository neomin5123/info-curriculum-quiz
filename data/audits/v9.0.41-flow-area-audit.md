## 1. Practical auto-flow
- Applies only when `회상 방식 = 실전 조합`.
- A task advances automatically only after every current answer field is graded `correct`.
- Delay: 950 ms, so the learner can see the success state before navigation.
- If another task remains in the current queue, normal `engine.next()` moves to it.
- If the current task is the last task, normal `engine.next()` increments `round`, rebuilds the queue, and practical sets rotate by round when alternatives exist.
- `near`, `unknown`, `wrong`, and `duplicate` states do not auto-advance.
- Pending auto-advance is cancelled by answer reveal, manual previous/next, manual next-round, area/scope change, and mode change.

## 2. Bottom area navigation
- The former compact area navigator was moved from the study-card header to the bottom of the study card.
- Visible labels: `← 이전 영역` / `다음 영역 →`.
- Specific-area scope: changes the actual area filter while preserving subject/family/stage/mode and restoring that scope's saved round/task.
- All-area scope: keeps `전체 영역` selected and jumps to the first task of the adjacent area in the current queue.
- Boundary buttons are disabled at the first/last available area.
