# CurriLoop 연습문제 출제 규칙 v1.1 — Exam Core

## 1. 연습 탭의 역할
- 연습 탭은 **실제 임용시험형 판단·적용 연습**만 담당한다.
- 공식 문장·용어의 단순 회상, 범주명 맞히기, 한 문장 빈칸은 총론/각론의 기존 빈칸 학습이 담당한다.
- 따라서 연습문제 후보가 기존 빈칸 기능과 실질적으로 같은 능력만 요구하면 production에 넣지 않는다.

## 2. 문제 유형 분류
- R1~R9 같은 **고정 문제 유형을 사용자에게 표시하거나 출제 비율 목표로 사용하지 않는다.**
- 실제 임용 문항은 회상·구별·적용·평가·전공지식을 한 문항 안에서 혼합하므로 하나의 유형으로 분류하면 정보 손실이 크다.
- 내부 QA에서는 고정 유형 대신 다음을 기록할 수 있다: 요구 판단 수, 결합된 원문 층위, 전공지식 결합 여부, 교수·학습/평가 결합 여부, 참고 기출 문항.

## 3. 난이도
- D1~D5 같은 임의 난이도 등급을 사용하지 않는다.
- 모든 production 문항은 `실전형`이라는 동일한 하한선을 통과해야 한다.
- 사용자에게는 실제 시험과 같은 **배점**만 표시한다.
- 2점형도 만들 수 있으나, 단순 문구·용어 빈칸만 묻는 2점형은 연습 탭에 넣지 않는다.

## 4. 기출형 하한선
문항은 다음 중 하나 이상을 만족해야 한다.
1. 공식 원문을 새로운 수업·평가·문제 상황에 적용한다.
2. 두 개 이상의 교육과정 요소/학교급/과목을 비교·연결한다.
3. 교육과정 요소와 실제 전공 내용·코드·알고리즘·데이터를 결합한다.
4. 잘못된 수업/평가 계획을 판단하고 수정 근거를 요구한다.
5. 최근 기출에서 확인된 복합 문항 구조를 새로운 내용으로 변형한다.

단, 정답 요소 중 일부가 직접 회상이어도 전체 문항이 위 조건을 만족하면 허용한다.

## 5. `과목 공통`의 취급
- `과목 공통`은 **콘텐츠 영역이 아니라 해당 과목의 교수·학습/평가 지침 위치**이므로 사용자 영역 태그로 사용하지 않는다.
- 교수·학습의 방향, 평가의 방향, 평가 방법 자체는 출제 가치가 있다.
- 다만 이를 단독 암기문제로 만들지 않고, 원칙적으로 구체적인 내용 영역의 수업·평가 상황과 결합한다.
- 예외는 2015↔2022처럼 교육과정 구조 자체를 비교하는 명시적 교육과정 문항이다.

## 6. 다중 과목·영역 태그
- production 데이터의 권위 태그는 `curriculumScopes[]`이며 각 원소를 `{subject, area}` 쌍으로 저장한다.
- `subjects[]`와 `areas[]`는 호환용 파생 인덱스일 뿐, 두 배열의 cross-product를 교육과정 대응 관계로 해석하지 않는다.
- 한 문항이 여러 과목 또는 여러 영역의 원문을 사용하면 **실제 연결된 과목↔영역 쌍을 모두 표시한다.**
- 과목+영역 필터는 반드시 동일한 scope pair가 일치할 때만 해당 문항을 포함한다.
- `과목 공통` 원문은 구체 영역의 교수·학습/평가 근거로 연결하되 사용자 영역 태그로 만들지 않는다.

## 7. 2015↔2022 비교
- 비교형은 전체 production 문제은행의 약 5~7%를 상한 가이드로 삼되 수량을 맞추기 위해 생성하지 않는다.
- 2015 공식 원문 전체가 확보되기 전까지는 기출에 명시적으로 인용된 근거 범위만 사용한다.

## 8. 문항 생성보다 선별 우선
- 목표는 N문항 생성이 아니라 **release gate를 통과한 문항 누적**이다.
- 후보 수와 production 수는 다를 수 있다.
- 특정 수량을 채우기 위해 하한선을 낮추지 않는다.

## 9. Production gate
1. 모든 정답 요소가 공식 원문/검증된 기출 근거로 추적된다.
2. 정답이 유일하거나 채점 의미 단위가 명시된다.
3. 기존 빈칸 학습과 실질적으로 중복되지 않는다.
4. 실제 임용형 판단·적용 가치가 있다.
5. 같은 source의 기존 production 문항과 다른 학습 기회를 제공한다.
6. 부정문·답 누설·복수정답·허용답·금지어 adversarial QA를 통과한다.
7. 앱에서 필터·채점·원문 보기·복습 연동이 정상 동작한다.

## 10. 최근 기출에서 확인한 설계 원칙
- 교수·학습/평가 지침은 실제 내용 영역과 결합해 출제된다.
- 내용체계·성취기준·해설·평가를 한 문항 안에서 연결하는 경우가 많다.
- 과목/학교급 비교는 실제 출제 가능성이 있으므로 유지하되 단순 명칭 암기로 축소하지 않는다.
- 전공지식과 교육과정의 연결 문항을 우선한다.

## v1.1 운영 규칙 — 150문항 확장부터 적용

- 목표 문항 수는 품질 기준을 낮추는 근거가 될 수 없다. 목표 수량에 도달하더라도 모든 문항은 동일한 production gate를 개별 통과해야 한다.
- 연습 문제는 단순 영역명·과목명·내용체계 범주·성취기준 번호 회상을 요구하지 않는다. 이 기능은 총론/각론 빈칸 학습이 담당한다.
- 최근 기출과 같이 교육과정 근거를 수업·평가·코드·알고리즘·데이터·시스템 사례와 결합하는 것을 우선한다.
- 동일 sourceId를 재사용하더라도 같은 기억 경로를 반복하지 않는다. 회상 문구만 바꾼 문제는 새 production 문항으로 세지 않는다.
- 비교문항의 비율을 강제하지 않는다. 2015 개정의 직접 근거가 충분한 경우에만 유지한다.
- 확장 때마다 기존 production 문항도 면책하지 않는다. 새 기준에서 약한 기존 문항은 재작성하거나 퇴출할 수 있다.

## v1.1 운영 규칙 — 180문항 확장 결과

- 확장은 균등 할당이 아니라 직전 커버리지 QA에서 확인된 결손을 목표로 한다. 이미 문항 수가 충분한 영역은 중요 source 커버가 100%가 아니더라도 수량을 맞추기 위해 문제를 추가하지 않는다.
- 공식 source 커버율은 품질 진단 지표이지 목표 함수가 아니다. 남은 source를 문제화했을 때 기존 문항과 다른 판단 경험을 만들기 어렵다면 확장을 중단한다.
- `sourceType`과 `sections` 메타데이터는 반드시 실제 `sourceIds`에서 파생되는 공식 원문 종류와 정확히 일치해야 한다. 누락·과잉 표기는 release gate 실패로 처리한다.
- 표적 확장 릴리스마다 ① exact scope 검증, ② canonical/accepted grading, ③ 부정문·금지 혼동어 adversarial grading, ④ 내부 실질 중복 검사, ⑤ 역사 기출 근접복제 휴리스틱 검사를 다시 수행한다.
- 180문항 단계에서는 즉시 수량을 더 늘리는 것보다, 현재 문제은행에서 실제 시험과 같은 혼합 세트를 구성하는 기능의 가치가 더 높다. 이후 추가 확장은 실전 세트 사용 결과나 새 결손 QA가 명확한 경우에만 실시한다.

## 실전 세트 구성 규칙 — v6.16.0

- 실전 세트는 **교육과정 연습문제은행 안에서 구성하는 5문항·20점 세트**이며, 정보·컴퓨터 전공 전체 80점 모의고사를 의미하지 않는다.
- 세트 후보 풀은 사용자가 현재 선택한 과목·영역·교육과정 필터를 그대로 따른다. 후보가 5문항보다 적으면 실전 세트를 시작하지 않고 필터를 넓히도록 안내한다.
- 세트 선택은 취약도보다 **범위 다양성·근거 독립성**을 우선한다. 같은 sourceId의 반복을 강하게 억제하고, 같은 과목·영역의 과도한 군집도 감점한다.
- 다중 과목/영역 문항은 실전 통합성을 위해 허용하되 5문항 세트에서 과도하게 몰리지 않도록 한다. 15·22 직접 비교 문항도 한 세트에 반복 배치하지 않는다.
- 세트 진행 중에는 개별 정답·해설·근거 원문을 공개하지 않는다. 전체 제출 후에만 일괄 채점 결과와 문항별 근거를 공개한다.
- 세트 제출 결과는 기존 문항별 풀이 통계와 원문 복습 연동에 정상적인 한 번의 시도로 반영한다. 새로고침 복원은 통계를 중복 적립하지 않는다.

## 적응형 출제 규칙 — v6.17.0

- 적응형 출제는 사용자에게 보이는 임의 문제 유형이 아니라 **공식 sourceId, 과목↔영역, 공식 원문 층위**의 실제 누적 수행 기록을 사용한다.
- sourceId 직접 취약도를 가장 강한 신호로 두고, 과목↔영역과 원문 층위 취약도는 보조 신호로 사용한다. 한 번의 실수로 전체 문제은행이 크게 왜곡되지 않도록 각 deficit은 상한을 둔다.
- 오답·모름·부분정답은 deficit을 증가시키고 정답은 감소시킨다. 적용형 문제의 실패를 원문 직접 암기 오답으로 간주하지 않는 기존 원칙은 유지한다.
- 거의 모든 문항에 등장하는 `성취기준` 원문 종류는 광역 원문-층위 가중치에서 제외한다. 개별 성취기준의 취약도는 sourceId 및 과목↔영역 기록으로 반영한다.
- 실전 세트는 시험 대표성을 위해 취약도 기반 선택을 사용하지 않는다. 다만 제출 결과는 장기 취약도 기록에 반영한다.
