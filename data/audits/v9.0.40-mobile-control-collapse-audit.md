# CurriLoop v9.0.40 mobile control collapse audit

## 변경 범위
모바일(760px 이하)에서 sticky 학습 설정 카드 전체를 접고 펼칠 수 있다.

접기 대상:
1. 과목
2. 영역
3. 출제 항목
4. 회상 방식
5. 학습 모드 (원문/따라치기/마스킹/빈칸 채우기)
6. 오답 카드 ON/OFF
7. 원문 출처

## 동작
- 기본값: 펼침
- 사용자가 접으면 `curriloop-mobile-controls-collapsed-v1`에 상태 저장
- 접힌 상태에서는 `학습 설정` 요약 바만 표시
- 요약 바에는 현재 과목·영역·출제 항목·회상 방식·학습 모드 표시
- 다시 누르면 전체 설정 복원
- 761px 이상 데스크톱에서는 저장값과 무관하게 항상 펼침
- `aria-expanded`, `aria-controls`, 동적 aria-label 적용
