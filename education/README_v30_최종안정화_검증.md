## 검증 수행 및 한계
- Node `--check` 실행 통과.
- 교육학 HTML·CSS·JS를 Chromium에 삽입한 20개 검사 통과: 개념/문항 로딩, 답안 저장 호출, 정답 공개, 체크 저장, 성공 평정 간격, 모의 페이지 재생성 후 기록 보존, 기출 필터와 출처, 복습 탭, 저장 실패에 대한 롤백, 390px 모바일 화면 가로 넘침 확인, JS 예외 없음.
- 모바일 교육학 화면 이미지 생성 및 확인.
- 내장 Python HTTP 서버는 `127.0.0.1` 요청에 HTTP 200을 반환했지만 Chromium의 관리자 정책(`ERR_BLOCKED_BY_ADMINISTRATOR`)으로 실제 URL 탐색이 실패함. **따라서 실제 origin에서 localStorage 영구 저장, 새로고침/재시작 후 보존, 메인 앱 iframe 연동, 실제 서비스 워커 동작을 검증하지 못함.**
- JS를 페이지에 직접 삽입하고 `localStorage`를 테스트 대역으로 구현했으므로 검증 결과를 실제 도메인 배포 성공과 혼동하면 안 됨.

## 실서비스 최종 승인 전 수동 점검
1. HTTPS 정식 주소에서 메인 커리루프 열기 → 교육학 탭 클릭 → 83개 개념·153문항 표시 확인.
2. 임의 문항에 답안 입력 → 새로고침 → 기록 보존 확인.
3. 복습 평정 → 새 탭 및 브라우저 재시작 → 통계와 다음 복습일 보존 확인.
4. 교육학 학습기록 백업 → 다른 브라우저에서 복원 → 답안·평정·체크 기록 일치 확인.
5. 모바일 실기기에서 탭, 입력, 모범답안, 백업 파일 선택 UI 확인.
6. 기존 v29 이용자와 다른 origin(도메인, 서브도메인, 프로토콜, 파일 경로)이면 localStorage가 자동 이동되지 않으므로 먼저 JSON 백업을 내보내 복원할 것.
7. 캐시가 과거 내용을 보여 주면 강력 새로고침하고 서비스 워커의 이전 캐시 제거 여부 확인.
