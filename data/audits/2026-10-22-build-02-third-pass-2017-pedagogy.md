# CurriLoop 3차 검증 — 2017학년도 교교론 7문항

> 전공 기출 PDF의 실제 문항·작성조건·도형을 대조하고, 2015 개정 정보과 교육과정·법령·원출처·접근 가능한 외부 풀이·2020년대 학술자료를 교차 확인한 독립 풀이 초안입니다. **268개 기존 답안·앱 내부 해설에는 변경이 없으며, 2017년 공식 채점기준과 직접 대조한 문항은 0건입니다.**

## 핵심 판정

- 7문항 모두 기존 핵심 답을 뒤집을 근거가 없었다.
- `2017-A-09`의 ㉢은 기존 답안의 효율 비교 취지는 타당하지만, 교육과정 직문구인 **“수행 시간의 관점에서 분석하여 가장 효율적인 알고리즘을 선택”**이 시험 답안으로 더 안전하다. 저장 답안은 보존한다.
- `2017-A-10`의 “새 언어 문법 부담 감소”는 합리적 추론이지만, 교육과정에 직접 적힌 근거는 **앞선 프로그래밍 학습과의 연계 및 동작 설계·제어 프로그램 작성 중심**이다. 저장 답안은 보존한다.
- `2017-B-01`, `2017-B-08`은 수업·평가기준 설계형이라 복수 타당안이 가능하다. 특히 B-08의 후대 공적 평가기준은 강한 비교 자료이지만 **2017 임용 공식 정답으로 간주하지 않는다.**
- 7문항 모두 계산·코드 실행 문제가 아니므로 실행 검산은 `not applicable`이다.

### 2017-A-09 — 다음은 2015 개정 교육과정에 따른 정보과 교육과정(교육부 고시 제2015-74호)에 제시된 중학교와 고등학교 정보과의 내용 체계 중 일부이다.

**기존 저장 답안:** ㉠ 핵심 요소, ㉡ 문제 분해. ㉢ 알고리즘 분석 지도 시에는 동일한 문제에 대한 복수의 알고리즘을 제시하고, 입력 크기나 연산 횟수 등 효율성을 비교·분석하도록 지도한다.

**3차 검증 핵심 답안:** ㉠ 핵심 요소, ㉡ 문제 분해. ㉢ 권장 정밀 표현: 동일한 문제를 해결하는 다양한 알고리즘을 제시하고 각 알고리즘의 성능을 수행 시간의 관점에서 분석하여 가장 효율적인 알고리즘을 선택하도록 지도한다.

**상세 풀이:** 중학교 추상화 내용 요소는 “문제 이해”와 “핵심 요소 추출”이므로 ㉠은 핵심 요소이다. 고등학교 추상화 내용 요소는 “문제 분석”과 “문제 분해와 모델링”이므로 ㉡은 문제 분해이다. ㉢은 고등학교 알고리즘 분석의 교수·학습 유의사항을 쓰는 부분이다. 교육과정은 동일한 문제에 대한 여러 알고리즘의 성능을 수행 시간 관점에서 분석하고 가장 효율적인 알고리즘을 선택하도록 지도하는 취지로 제시한다. 앱의 기존 답안도 복수 알고리즘의 효율 비교·분석이라는 핵심은 맞지만 “입력 크기나 연산 횟수”를 예시로 추가해 공식 교육과정 문구보다 일반화되어 있다. 따라서 저장 답안을 고치지는 않고, 상세 검증 초안에서 교육과정의 직접 표현을 우선 답안으로 기록한다.

**한계 및 반례:** 공식 임용 채점기준이 없어 “수행 시간” 대신 연산 횟수·입력 크기 비교가 어느 범위까지 허용되는지는 확정할 수 없다. 기존 답안은 알고리즘 시간 효율의 실질적 비교 방법으로 개념적으로 타당하나, 문항이 교육과정상의 “지도상의 유의 사항”을 요구하므로 시험 답안 안전성은 교육과정 직문구가 더 높다.

**정밀성 메모:** 앱 저장 답안은 보존. 시험용 권장 표현에서는 “수행 시간의 관점에서 분석하여 가장 효율적인 알고리즘 선택”을 우선한다.

### 2017-A-10 — 다음은 중학교 정보 교사가 컴퓨팅 시스템 영역의 수업을 위해 작성한 <동기 유발 자료>와 <지도상의 유의 사항>이다.
