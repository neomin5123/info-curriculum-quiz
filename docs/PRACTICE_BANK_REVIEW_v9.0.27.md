# CurriLoop 이전 연습문제 사용가치 검토 — v9.0.27

검토 대상: v8.0.3 `data/questions/production.js`의 learner-facing production bank 31문항.

## 결론

- 높음: **16문항**
- 보통: **10문항**
- 낮음: **5문항**
- 현재 v9 본 학습에 31문항을 그대로 복원하는 것은 권장하지 않는다.
- 높은 가치 문항은 `실전 연습` 후보로 보존하고, 보통 문항은 선택형 보조 연습, 낮은 문항은 격리/재작성하는 편이 낫다.
- 특히 EX-028~031은 실제 2024~2025 기출의 문항 구조를 참고한 `legacyEvidence`가 명시되어 있어 상대적으로 우선순위가 높다.

## 평가 기준

1. 교육과정 원문 회상만이 아니라 자료 해석·계산·코드·판단을 함께 요구하는가
2. 답이 상식이나 보기만으로 지나치게 자명하지 않은가
3. 1점 단위 정답이 비교적 명확하여 자동/부분 채점이 안정적인가
4. 정보-컴퓨터 임용의 실제 구조와 연결되는 근거가 있는가
5. 반복해서 풀 가치가 있을 만큼 전공 지식 또는 교육과정 연결성이 있는가

## 별도 일반 암기 보조 bank

`general-bank.js`는 총 **28문항**이며 구성은 competency 5, history 10, hours 4, subjects 9이다.

이 묶음은 핵심역량·인간상·과목 편제·역사·이수시간 같은 사실 회상 중심이다. 현재 임용 대비 우선순위에서는 production 31문항보다 낮게 보는 편이 타당하다. 특히 역사/편제 문항은 직접 기출 근거가 확인되지 않은 상태에서 반복 비중을 높이면 본 교육과정 원문과 전공 계산 연습 시간을 잠식할 수 있다.
