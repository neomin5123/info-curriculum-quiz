# CurriLoop

2022 개정 정보과 교육과정 암기·복습·기출형 연습 PWA입니다.

## 실행
정적 웹 서버의 루트에서 `index.html`을 제공하면 됩니다. 서비스 워커가 루트 경로를 기준으로 동작하므로 파일을 직접 여는 방식보다 HTTP(S) 서버 사용을 권장합니다.

## 디렉터리 안내
- `data/curriculum/`: 교육과정 원문 기반 corpus와 별도 비교·전환 mapping (역할별 하위 폴더 분리)
- `data/questions/`: 현재 앱이 사용하는 production 문제은행
- `data/learning-aids/`: CurriLoop가 만든 암기 보조 자료(공식 원문 아님)
- `js/`: 앱과 엔진 로직
- `docs/`: 현재 적용되는 규칙·QA·구조 문서
- `tests/`: 현재 production에 대한 회귀 테스트
- `archive/`: 과거 문제은행·규칙·QA·테스트

현재 기능 버전은 **v7.6.1**입니다. v7.6.0의 적응형 오늘 학습 플래너를 유지하면서 **완료 인출 게이트, backlog 기반 새 진도 감속/정지, 실제 누적 혼합 점검, 분할 영역 마지막 세션의 구조 연습**을 보강했습니다. 기존 2022 공식 corpus(6과목/33영역/662문장)와 EX-001~031 문제은행 내용은 그대로 유지합니다.




## v7.6.1 인출 기반 완료 + backlog 적응 + 누적 혼합 점검

- 앱 첫 화면은 `오늘`이며 `예정 복습 → 새 범위 → 누적 혼합 → 속도`를 한 화면에서 안내한다.
- 새 범위의 `완료`는 마지막 화면까지 넘긴 것만으로 처리하지 않는다. **핵심 빈칸·통회상/정확화에서 실제 채점 시도**가 있어야 하고, 당일 지연 재인출이 남아 있으면 먼저 처리해야 한다. 다만 같은 항목의 당일 재인출을 두 번 다시 실패하면 무한 반복하지 않고 다음 날 복습으로 이월한다. 중학교 정보의 마지막 영역 세션에서는 연결형 구조 연습까지 끝내야 완료된다.
- `완료`는 복습 종료가 아니라 **장기 복습 진입**이다. 정확 인출은 기본 1→3→7→14→30→60일 간격으로 다시 나오며, 중학교 정보 통회상은 여러 날짜의 성공을 거쳐 `학습됨 → 안정화 중 → 숙달`로 올라간다.
- 하루 복습 예산은 암기가 느려져도 최소 20개 수준을 유지한다. backlog가 오늘 예산을 넘으면 **복습량을 줄이는 대신 새 원문 목표부터 75% → 50% → 중단** 순으로 감속한다.
- 기본 새 원문 목표는 18문장이고 개인 속도·첫 인출 정확도에 따라 8~22문장에서 적응한다. 끝내지 못한 범위는 다음 날 새 진도를 추가하지 않고 그대로 이어서 학습한다.
- 7일 주기 정리일에는 단순히 새 진도를 막는 것이 아니라, 이미 학습한 항목 중 **오래 안 본 것·오답/모름 이력이 있는 것·서로 다른 영역**을 우선하여 약 6개의 누적 혼합 점검을 실제 복습 큐에 추가한다.
- 큰 영역이 여러 세션으로 나뉘어도 이전에 완료한 section과 현재 section을 합쳐 영역 전체가 끝나는 마지막 세션이면 **구조 연습을 반드시 제시**한다.
- 중학교 정보의 `지식·이해 / 과정·기능 / 성취기준`은 개별 핵심 빈칸을 장기 큐에서 제외하고 통회상 묶음으로 유지한다. 일반 문장의 여러 빈칸도 장기 복습에서는 문장 단위 일정으로 합쳐 복습 폭증을 억제한다.
- 목표량 조절 정확도는 재시도 결과로 덮어쓰지 않고 **첫 시도**만 사용한다. 중등 정보에서는 통회상 55% · 핵심 빈칸 35% · 구조 연결 10% 비중으로 종합한다.
- 학습 플래너 상태는 백업/복원에 포함한다(backup schema v10).
- **기출형 production 문제은행(EX-001~031)은 추가·수정하지 않는다.**

### v7.6.0에서 유지되는 적응 원칙

- 1일 완료 + 85% 이상 첫 인출 정확도가 반복될 때만 새 원문 목표를 점진적으로 늘린다.
- 1일 완료라도 70% 미만이면 감속하며, 2~3일 이상 걸리면 정확도가 높을수록 감속 폭을 줄인다.
- 첫 회독 진행률, 하루 새 원문 목표량, 최근 첫 인출 정확도를 홈에서 확인한다.


## v7.5.4 핵심 빈칸 지연 재인출 + 연결 중심 구조 연습

- 중학교 정보 `핵심` 빈칸의 틀림/모름/유사 답안은 정답 확인 뒤 즉시 반복하지 않고 2~4개 다른 핵심 빈칸 뒤에 다시 꺼낸다.
- 핵심 빈칸의 당일 보수와 실전 통회상의 당일 보수 카운터를 분리한다.
- 구조 연습에서 형태만 보고 답할 수 있는 범주 판별 문제를 제거한다.
- 구조 연습은 `성취기준 ↔ 내용 요소`, `성취기준 해설 ↔ 성취기준` 연결만 사용하고 영역별 4~6문항으로 제한한다.
- **기출형 production 문제은행(EX-001~031)은 추가·수정하지 않는다.**

## v7.5.3 중등 정보 구조 연습 정리

- 구조 연습을 `출처 위치 맞히기 / 위치→원문` 중심에서 **구별·연결 연습**으로 재정의한다.
- `지식·이해 / 과정·기능 / 가치·태도` 내용 요소는 드롭다운이 아니라 선택형 칩으로 범주를 구별한다.
- 성취기준 해설은 문제에서 성취기준 코드를 숨기고, 같은 영역의 성취기준 선택지 중 직접 연결되는 성취기준을 고른 뒤 채점한다.
- 정답 코드는 채점 후에만 공개한다.
- 구조 연습은 영역별 **중복 없는 8문항 세트**로 종료되며, 세트마다 연결 문항을 최소 1개 포함한다.
- 단어만 보고 답이 드러나는 영역/출처 위치 맞히기와 실전 통회상과 중복되는 위치→원문 유형은 제거한다.
- **기출형 production 문제은행(EX-001~031)은 추가·수정하지 않는다.**

## v7.5.2 중등 정보 학습 패널 가독성 개선

- 상단 설정을 `과목 / 영역 / 출제 항목`으로 묶고, 중등 정보에서는 세 선택창이 동일 폭으로 전체 너비를 사용한다.
- `학습 방식`을 별도 구획으로 분리하고 `원문 보기 / 마스킹 / 따라치기 / 빈칸 채우기 / 구조 연습`만 배치한다.
- 중등 정보의 `핵심 / 실전`은 별도 드롭다운 대신 `빈칸 채우기` 선택 시 나타나는 세그먼트 토글로 변경한다.
- `진행`, `전체 채점`, `원문 출처`, `현재 단원 초기화`는 하단 행동 바에 분리해 학습 방식과 도구를 시각적으로 구분한다.
- 모바일에서는 선택창과 행동 바가 줄바꿈되며, 기존 학습·통회상·복습 로직은 변경하지 않는다.


## v7.5.1 중등 정보 자유 통회상 파일럿

중학교 정보에서는 난이도 등급 대신 학습 방식의 역할을 분리합니다. `원문 보기 → 마스킹 → 따라치기 → 빈칸 채우기 → 구조 연습`을 사용할 수 있고, 빈칸 채우기에서만 `핵심 / 실전`을 고릅니다.

- **핵심**: 기존의 짧은 핵심어 빈칸으로 첫 인출을 만든다.
- **실전**: `지식·이해`, `과정·기능`은 **항목 수와 슬롯을 미리 보여주지 않는 단일 입력창**에서 한 항목당 한 줄로 목록 전체를 자유회상한다. `성취기준`은 코드만 보고 문장 전체를 회상한다.
- **항목별 진단**: 목록을 통으로 쓰더라도 내부 채점은 공식 항목별로 매칭하여 누락·표기 확인·순서 이동을 구분한다.
- **같은 날 재인출**: 누락·오답 항목은 정답 확인 뒤 몇 항목 후 개별적으로 다시 묻는다.
- **다른 날 재인출**: 장기 복습은 전체 묶음으로 다시 묻는다. 최초 정확 통회상은 `학습됨`, 날짜를 건넌 재성공은 `안정화 중`, 1일→3일→7일 간격을 거친 뒤 다시 정확히 회상하면 `숙달`로 표시한다.
- **암기 강도 표시**: 지식·이해/과정·기능/성취기준=`정확 암기`, 목표/핵심 아이디어/가치·태도/해설·고려사항=`키워드 +@`, 성격/교수학습·평가 공통 원칙=`키워드`.
- **구조 연습**: 공식 문구가 어느 범주·출처 위치에 있는지, 또는 위치에서 공식 항목을 다시 복원하는 연습을 제공한다.

다른 과목은 회귀 위험을 줄이기 위해 v7.4의 기존 학습 방식을 유지하며, 중등 정보 파일럿 검증 후 순차적으로 전환합니다.
