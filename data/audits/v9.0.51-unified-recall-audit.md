# CurriLoop v9.0.51 unified recall audit

## Scope
- Delayed retry and daily SRS review now share one prompt/meta model (`recallPromptModel`).
- Daily review renders one active card at a time.
- Daily review metadata uses the source line's actual area/family and `n/m` position.
- Knowledge-understanding daily review is per official content-element line, not whole-area multi-input recall.
- Correct daily reviews auto-advance after brief success feedback.
- Wrong/near/unknown daily reviews keep the answer visible until Enter acknowledgment.
- Scheduling state remains separate: main study progress, field retry queue, and long-term SRS are not merged.

## Regression result
- `npm test`: PASS
- curriculum data: 270 lines / 370 presentation units (unchanged)
- Browser E2E: not run; static/behavior regression suite and JS syntax checks passed.
