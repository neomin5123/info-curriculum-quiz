# CurriLoop 연습문제 출제 규칙 v1.2 — ExamLike Core

## 최상위 원칙
문항 수 목표를 두지 않는다. 실제 임용 시험지에 4점 문항으로 들어가도 구조적으로 어색하지 않은 문제만 production으로 승격한다.

## Production 필수 게이트
1. **공식 근거**: 정답·해설의 모든 핵심 판단이 공식 교육과정 sourceId에 추적 가능해야 한다.
2. **정답 유일성**: 주어진 조건에서 합리적인 대안 정답이 남지 않아야 한다.
3. **빈칸 대체 금지**: 단순 용어·학교급·과목·행동동사 회상만으로 4점을 구성하지 않는다.
4. **정답 노출 금지**: 문제 서술의 반대말만 쓰면 맞는 ‘틀린 교사 고치기’ 유형을 독립 4점 문항으로 두지 않는다.
5. **구체 자료**: 코드, 데이터, 표, 알고리즘 수행 과정, 학생 답안, 평가표, 수업 자료, 프로젝트 기록 등 적어도 하나의 구체적 판단 자료를 포함하는 것을 원칙으로 한다.
6. **복합 판단**: 교육과정 판단 외에 전공지식 처리, 수업·평가 설계, 자료 해석 중 하나 이상을 결합한다.
7. **4점 밀도**: 최소 두 개의 독립된 판단층이 있어야 하며, 단순 2점 회상 두 개를 붙여 4점으로 만들지 않는다.
8. **기출 구조 적합성**: 최근 임용의 ‘교육과정 원문/수업자료 + 전공 내용 + 작성 방법’ 결합 구조와 비교했을 때 충분한 밀도를 가져야 한다.
9. **채점 강건성**: 공식 정답, 허용 표현, 오개념, 부정문, 이중부정 공격을 모두 통과해야 한다.
10. **수량 독립성**: 영역 커버를 채우기 위해 품질 기준을 낮추지 않는다. 빈 영역은 좋은 문항이 생길 때까지 빈 상태로 둔다.

## Quarantine 조건
다음 중 하나라도 해당하면 learner-facing production에서 제외하고 재작성 후보로 보관한다.
- 상식만으로 풀리는 문제
- 학교급/과목명 매칭 중심 문제
- 행동동사만 맞히는 문제
- 문장 반전만으로 답이 드러나는 오류 수정 문제
- 원문 빈칸 학습과 실질적으로 같은 문제
- 기술적·교육적 자료 처리 없이 교육과정 문장을 재진술하는 문제
- 실제 임용에서는 독립 4점이 아니라 한 소문항 정도에 그칠 밀도의 문제

## 확장 방식
`결손 분석 → 소수 후보 작성 → 독립 재풀이 → 기출 구조 비교 → 채점 Red Team → production 승격`

한 번에 대량 생성하지 않는다. 새 문항이 기존 production의 하한선보다 약하면 추가하지 않는다.
