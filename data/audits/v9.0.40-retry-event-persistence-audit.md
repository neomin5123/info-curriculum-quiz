# CurriLoop v9.0.40 — Retry Event Persistence Audit

## Requested behavior
한 번 오답/모름/표기 확인으로 생성된 오답 카드는 이후 메인 학습 입력칸을 정답으로 고쳐도 취소되지 않는다.

## Resolution rule
- 메인 화면에서 나중에 정답: 카드 유지
- 카드 내부에서 재인출 정답: 카드 제거 (`재인출 완료 ✓`)
- 카드 내부 실패: 기존 규칙대로 재예약/취약 기록
- `오답 카드 OFF`: 대기 카드 명시적 삭제
- `복습 데이터 초기화`: 대기 카드 명시적 삭제

## Scope
교육과정 sourceText, presentation, Stage3R, 장기 SRS 간격은 변경하지 않았다.
