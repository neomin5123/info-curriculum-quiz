# CurriLoop 교육학 통합 문제풀이 v6

## 핵심 변경
- **교육학 탭은 개념 학습 / 문제 풀이 / 오답·복습**으로 구성됩니다. 독립된 '기출 변형' 탭은 제거했습니다.
- 문제 풀이에서 '전체 문제 / 개념 확인 / 기출 변형' 필터를 사용합니다. 동일한 답안 입력·정답 확인·자기 평정·반복 복습 흐름으로 진행합니다.
- 마지막 교육학 필기 PDF 기반 개념 50개, 개념 확인문제 70개, 기출 소재 변형문제 25개, **총 95개 문제**를 포함합니다.
- 기출 소재 문제는 실제 기출 지문의 재현이나 공식 정답이 아닙니다. 관련 학년도, PDF 쪽, 소재를 화면에 표시합니다.

## 중요도가 낮은 개념 선별 제거
'절대 나오지 않는다'는 근거 없는 예측은 하지 않습니다. 핵심 이론 대비 상대적 출제 활용성, 다른 개념과의 중복, 지나치게 일반적인 설명, 법령 변동 가능성 등을 기준으로 제한적으로 제외했습니다.

- edu-011: 일반 교수법 단독 암기: 강의법의 일반적 설명은 출제 변별성이 낮음
- edu-012: 일반 교수법 단독 암기: 토의법의 포괄적 정의는 변별성이 낮음
- edu-016: 협동학습 세부 유형 Co-op Co-op: 핵심 STAD·직소에 비해 우선순위 낮음
- edu-022: 프로이트 성격 구조: 교육학 논술 핵심 교수·학습 적용과의 직접성이 상대적으로 낮음
- edu-038: 장의존형·장독립형: 교육학 논술 대비 우선순위 상대적으로 낮음
- edu-041: 홀랜드의 직업적 성격 유형: 현재 수록 범위의 핵심 교수·평가 이론과의 연계성이 낮음
- edu-045: 교육과정 운영 관점: 구체 모형·유형 학습과 비교할 때 우선순위 낮음
- edu-058: 학교운영위원회 구성 메모: 특정 구성 비율·구성 사항의 법령 변동 가능성과 낮은 개념 일반성

중복 또는 낮은 추가 학습 효용의 변형 문제 3개도 정리했습니다: drill-d19, drill-d23, drill-d28

## 적용
1. 현재 ZIP과 학습 기록을 백업합니다.
2. 원본 `info-curriculum-quiz-main.zip`을 압축 풉니다.
3. 이 패치를 원본 프로젝트의 **상위 폴더**에서 압축 해제하고 같은 이름의 파일을 덮어씁니다.
4. `info-curriculum-quiz-main/index.html` 실행 후 교육학 → 문제 풀이에서 문제 종류를 확인합니다.
5. 기존 v5에서 복습한 기출 변형 문제는 별도의 저장 영역에 남아 있다면 통합 문제 풀이 기록으로 읽어옵니다.

## 주의
- v5 또는 앞선 버전에 저장된 학습기록은 제거하지 않습니다. 제외한 개념의 이전 기록도 삭제하지 않지만, v6의 학습 목록에서는 보이지 않습니다.
- 이 변경은 출제 확률의 통계적 추정이 아닙니다. 편집자가 제안한 우선순위 기반 간소화입니다.
- 필기 PDF 내용을 완전 전사한 것은 아닙니다.
- 동일 폴더를 다른 배포 URL 또는 도메인으로 변경하면 localStorage 기록은 자동으로 이전되지 않습니다.
