# CurriLoop v7.2.0 — Historical Gap QA

## 1. 목적

v7.1.0의 28문항을 다시 대량 확장하지 않고, 현재 production에 없는 기출형 사고 구조를 한 가지씩 보강한다. 이번 추가 대상은 **교육과정 원문 × 교수설계 모형(ASSURE)** 결합 구조다.

## 2. 기출 구조 근거

2024학년도 전공B 3번은 2022 개정 중학교 정보과 교육과정의 `성취기준 적용 시 고려 사항`과 `교수·학습의 방향`에 제시된 학습자 수준/디지털 역량 관련 문장을 제시하고, 이를 ASSURE 모형의 단계와 연결하여 판단하게 한다.

이번 문항은 그 **구조적 요구**만 참고하고, 과목·영역·상황·자료·답안은 새로 설계했다.

## 3. 신규 EX-029

- 과목: 데이터 과학
- 영역: 데이터 모델링과 평가
- 배점: 4점
- 공식 근거:
  - `DS-03-AC-ST-01` — 데이터 분석에 활용할 수 있는 도구 탐색
  - `DS-03-AC-CO-02` — 학습자의 디지털 역량 사전 파악, 인지적 부담, 기기/운영 체제 독립성, 접근성
- 기출 구조 참조: 2024 전공B 3번
- 1점 요소:
  1. 디지털 역량
  2. ASSURE의 학습자 분석
  3. 학습자 자료와 도구 특성에 따른 Q 선택
  4. 기기/운영 체제 독립성 → 접근성 보장

## 5. 신규 문항 채점 공격

EX-029에 대해 다음을 추가 확인했다.

- 공식 정답: 4/4
- `컴퓨팅 사고력 / 방법·매체·자료 선정 / P / 웹 브라우저에서 실행된다`: 0/4
- 마지막 서술에서 `운영 체제`만 적는 불충분 답: 해당 1점 미획득

즉, 단순 관련 키워드 하나만으로 접근성 근거 점수를 얻는 것을 방지했다.

## 6. 기출 직접 복제 검사

2014 및 2016~2026 A/B 24개 PDF를 텍스트로 변환하여 EX-029의 stem+작성방법과 연속 token을 비교했다.

- 10-token 연속 일치: 0
- 12-token 연속 일치: 0
- 8-token 일치: 1건. `자료이다 작성 방법에 따라 서술하시오 [4점] (가)`에 해당하는 시험 공통 보일러플레이트였다.

따라서 구조는 기출형을 따르되, 의미 있는 문장/상황의 직접 복제 신호는 발견되지 않았다.

## 7. 제한 사항

- 이번 증분은 신규 문항 1개 추가가 목적이므로 v7.1에서 완료한 28문항 전수 재감사를 다시 반복하지 않았다.
- 실제 모바일 브라우저의 fresh touch/scroll smoke는 이번 증분에서도 별도로 수행하지 않았다. 정적 자산, 채점 엔진, 세트 생성 및 UI 코드 경로 회귀 테스트는 통과했다.
