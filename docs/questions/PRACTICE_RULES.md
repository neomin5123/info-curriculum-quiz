# CurriLoop 연습문제 출제 규칙 v1.6 — v7 Exam-paper Standard

v1.5의 자료 연결·배점·해설 규칙을 유지하고, v7.1부터 **1점 원자성**과 **기출 구조 공백 우선 보강**을 release gate에 추가한다.

## 1. 최상위 판정: 실제 임용 시험지에 놓아도 어색하지 않은가
- 교육과정 내용을 묻는다는 이유만으로 production에 넣지 않는다.
- 문두, `(가)·(나)·(다)`, 대화·지도안·표·코드·학생 산출물, `<조건>`, `<작성 방법>`은 필요한 경우 실제 기능을 가져야 한다.
- 형식만 기출처럼 꾸민 장식용 자료는 금지한다.

## 2. 자료 간 연결
- 4점형은 최소 한 채점 요소가 둘 이상의 자료를 함께 해석해야 결정되도록 설계한다.
- 자료 하나만 읽어도 모든 답이 보이면 재작성한다.
- 정답을 거의 그대로 말해 주는 교사 발언이나 ‘명백한 오답을 반대로 고치기’ 구조는 억제한다.

## 3. 교육과정 근거의 층위
- `내용 체계 / 성취기준 / 성취기준 해설 / 성취기준 적용 시 고려 사항 / 교수·학습 / 평가` 중 어느 층위를 근거로 답하는지 `<작성 방법>`에 명시한다.
- 공식 행동 동사(탐색, 분석, 비교·분석, 설계, 구현, 평가 등)는 임의로 등치하지 않는다.
- sourceId가 실제 공식 원문과 연결되지 않으면 production 불가.

## 4. 전공지식 처리
- 코드 실행·수정, 알고리즘 추적, 데이터 계산·해석, 장치 역할 판별, 모델 평가 등 실제 처리를 포함한다.
- 교육과정 문장만 외워도 만점이거나, 반대로 전공지식만으로 교육과정 판단 없이 만점인 4점형은 원칙적으로 재작성한다.
- 제시 자료로 말할 수 있는 범위를 넘어 인과나 효과를 단정하지 않는다.

## 5. 배점
- 4점형 = 정확히 1점 채점 요소 4개.
- 2점형 = 정확히 1점 채점 요소 2개.
- 한 입력칸이 2점이면 두 의미 단위를 독립 채점한다.
- 한 요소의 오답이 다른 요소를 자동 연쇄 오답으로 만들지 않도록 가능한 한 독립성을 확보한다.

## 6. 1점 원자성
- 1점짜리 task가 “두 개/세 개를 쓰시오”처럼 복수의 독립 답을 동시에 요구하지 않도록 한다.
- 한 문장 답안이라도 독립적으로 부분점수를 줄 핵심 요소가 둘 이상이면 answerUnit을 분리하고 그만큼 배점을 배정한다.
- 다만 하나의 고유 명칭·공식 문구·하나의 관계를 완성하는 데 필요한 구성어는 하나의 답으로 취급할 수 있다.
- 1점 문항에서 여러 교육과정 요소를 한꺼번에 나열시키지 않는다.

## 7. 2점형
- 답이 단답이어도 반드시 보기·표·코드·규칙·대화 중 하나 이상을 읽고 처리해야 한다.
- 단순 교육과정 원문 빈칸 2개만 제시하는 문제는 각론 회상 학습으로 보낸다.

## 8. 20점 실전 세트
- v7부터 실전 세트는 고정 문항 수가 아니라 **정확히 20점**을 기준으로 구성한다.
- 전체 필터에서는 가능하면 `4점×4 + 2점×2 = 20점`의 혼합 구성을 우선한다.
- 좁은 필터에서는 정확히 20점을 만들 수 있는 다른 조합을 허용한다.
- 20점을 만들 수 없으면 더 작은 세트를 임의 생성하지 않고 필터를 넓히도록 안내한다.
- 동일 sourceId, 동일 과목·영역 과도 중복을 억제한다.

## 9. 기출 구조 공백 우선 보강
- 신규 문항을 만들기 전에 2014·2016~2026 기출의 교육과정 결합 문항을 현재 production과 구조적으로 대조한다.
- 현재 production에 **유사한 문항 구조가 하나도 없는 기출 유형**을 단순 영역 균형보다 우선한다.
- 여러 연도에서 반복된 미커버 구조를 단발성 구조보다 우선하고, 동일 조건이면 최근 기출을 우선 참조한다.
- 기출의 문장·수치·상황을 복제하지 않고, `자료의 역할 → 요구 사고 → 채점 구조`만 추출해 새 소재로 설계한다.
- 예: `평가 루브릭 → 학생 답안 판정 → 구체적 피드백`, `교육학 모형 ↔ 교육과정 근거`, `개정 교육과정 비교`, `연계 성취기준 재구성`.

## 10. 해설
채점 후 통합 해설은 다음을 제공한다.
1. 해결 흐름
2. 각 1점 채점 요소의 실제 획득 여부(0/1점)
3. 정답과 해당 요소의 이유
4. 교육과정 근거 층위와 sourceId
5. 임용형 포인트
6. 혼동 주의

실전 세트에서는 최종 제출 전 정답·근거·해설을 공개하지 않는다.

## 11. production release gate
- sourceId 실재
- 정답 유일성 또는 허용 답의 명시적 범위 설정
- 문항 배점 = task 배점 합 = answerUnit 배점 합
- 모든 answerUnit 정확히 1점
- 1점 task가 복수의 독립 답을 요구하지 않는지 검사
- 신규 문항은 기출 구조 공백 감사에서 추가 우선순위가 설명 가능해야 함
- 4점형 4개 / 2점형 2개 answerUnit
- 공식 정답 만점
- 복수 unit task의 부분점수 격리
- 빈 답·부정문·금지 오개념 채점 회귀 통과
- 통합 해설과 근거 원문 연결 존재
- 자료 간 연결성 수동 감사
- 상식만으로 해결되는지 수동 감사
- 역사 기출 문장·상황의 직접 복제가 아닌 구조적 유사성 유지
- 문제 수를 맞추기 위한 약한 문항 추가 금지


## 2015↔2022 비교 문항

- 비교 문항은 `comparison2015: true`로 표시한다.
- 2015 source ID와 2022 source ID를 모두 `sourceIds`에 연결하여 근거 팝업에서 양쪽을 검증할 수 있게 한다.
- mapping의 `유지/이동/통합/분화/신설/삭제`는 CurriLoop 분석 메타데이터이며, 이를 교육부 공식 분류처럼 문항 정답으로 요구하지 않는다.
- 학교급·내용 위치 변화와 성취기준 해설의 범위 차이를 구분한다. 이름이 비슷하다는 이유만으로 동일 내용으로 처리하지 않는다.
- 2015 전환 참조 corpus가 전체 2015 암기 corpus가 아니라는 점을 해설·QA에서 명시한다.
