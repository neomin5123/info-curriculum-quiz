CurriLoop v6.0.0 Public Final

배포:
1. 최종 ZIP의 내용을 GitHub 저장소 루트에 모두 덮어씁니다.
2. index.html, service-worker.js, manifest.webmanifest, icons/, robots.txt, sitemap.xml을 함께 올립니다.
3. main에 커밋하면 Vercel 자동 배포를 사용합니다.
4. 배포 후 https://curriloop.vercel.app 에서 버전이 v6.0.0인지 확인합니다.
5. 기존 PWA는 화면의 업데이트 알림에서 새로고침하거나 앱을 완전히 닫았다가 다시 엽니다.
6. 설치형 PWA에서 온라인 1회 실행 → 오프라인 재실행을 확인하면 배포 검증이 완료됩니다.

데이터 호환:
- 기존 easy/normal/yaho 내부 키를 유지합니다.
- 구형 hard/어려움 기록은 normal/정밀로 자동 마이그레이션합니다.
- stable line ID를 유지하므로 기존 오답 연결을 최대한 보존합니다.
- 백업 가져오기 전 스냅샷을 저장하고, 검증/쓰기 실패 시 롤백합니다.
