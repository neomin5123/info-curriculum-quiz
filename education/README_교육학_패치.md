# CurriLoop 교육학 텍스트 학습 패치 v2 (정리·검증판)

## 구성

기존 CurriLoop의 `학습 / 복습 / 기출문제`에 최상위 `교육학` 탭을 추가합니다. 교육학은 별도의 `education/index.html`로 작동하므로 기존 전공 학습 데이터와 학습 기록을 덮어쓰지 않습니다.

교육학 탭 안에는 다음 네 개 화면이 있습니다.

1. **개념 학습**: 필기 PDF를 참고해 정리한 텍스트 단원(소제목, 개념 정의, 비교·절차 포함)을 읽습니다. PDF 원본 뷰어는 넣지 않았습니다.
2. **문제 풀이**: 개념별 필요량에 따라 개수가 다른 서술형 자체 제작 문제를 풀고, 모범적인 핵심 답안을 확인하며 4단계 자기 평정으로 간격 반복 복습 일정을 정합니다.
3. **오답·복습**: 오늘 복습할 문제와 취약 문제를 분리해 다시 풉니다.
4. **기출 연습**: 제공된 교육학 기출 PDF의 텍스트 추출 페이지를 열고 스스로 논술 답안을 작성합니다. 본문의 그림·표·문자 순서는 원본과 다를 수 있습니다. 공식 채점 기준은 수록되어 있지 않습니다.

### 현재 데이터 범위

- 필기 PDF 기반 **58개 개념 / 78개 자체 제작 질문**.
- 기출 PDF **15쪽의 추출 텍스트**.
- 제공된 `교육학_기출_7문항형_암기노트_가독성개선.pdf`는 질문 설계 참고 자료로 사용했으며 질문 개수를 7개로 고정하지 않았습니다.
- **아직 필기 PDF 23쪽 전체를 완전 전사하거나, 모든 기출의 논점과 모든 개념을 일대일 연결한 완성본이 아닙니다.** 일부 내용은 판독과 표준 교육학 개념을 바탕으로 편집·보정했습니다. 어려운 시험 용어는 원문과 대조해 주세요.

### 저장 방식

- 교육학 복습 기록, 답안 초안, 기출 서술 답안은 브라우저 `localStorage`의 `curriloop:education:text:v1`에 저장됩니다.
- `학습기록 백업`은 해당 교육학 데이터만 JSON으로 내보냅니다. `백업 복원`은 *기존 교육학 기록을 교체*합니다.
- 기존 정보·컴퓨터 학습 기록과 분리되어 있습니다.
- **브라우저/기기를 변경하거나 저장 공간을 지우면 기록이 사라질 수 있으므로 JSON 백업을 이용하세요.**

## 설치 방법

1. 먼저 기존 커리루프 디렉터리와 학습기록을 백업합니다.
2. 기존 `info-curriculum-quiz-main.zip`을 폴더에 압축 해제합니다.
3. 제공한 `CurriLoop_교육학_텍스트_패치.zip`을 **원래 `info-curriculum-quiz-main` 폴더의 바로 위 폴더**에 압축 해제하고 동일 파일 덮어쓰기를 허용합니다.
4. 기존 폴더의 `index.html`을 실행하거나, 사용 중인 정적 웹 호스팅에 폴더 구조 그대로 업로드합니다.
5. 최상위 `교육학` 버튼 → `개념 학습 / 문제 풀이 / 오답·복습 / 기출 연습`을 확인합니다.
6. 기존 PWA/브라우저 캐시 때문에 이전 화면이 나오면 강력 새로고침(Ctrl+Shift+R) 후 다시 확인합니다.

> 호스팅 서버에 올릴 때 `education/` 디렉터리의 5개 파일을 누락하지 마세요. `file://`로 실행한 일부 브라우저 환경에서는 로컬 저장 또는 다른 기존 기능의 자원 로딩이 제한될 수 있으므로 정적 웹서버 실행을 권장합니다.

## 덮어쓰는 파일

- `index.html`: 교육학 탭 버튼과 iframe 컨테이너 추가
- `js/app.js`: 주 메뉴의 교육학 탭 전환 기능 추가
- `assets/css/app.css`: 교육학 iframe 크기 스타일 추가

## 새로 추가하는 파일

- `education/index.html`: 교육학 UI
- `education/style.css`: 디자인
- `education/app.js`: 문제/복습/기출 학습 로직
- `education/data.js`: 개념 텍스트와 자체 제작 질문
- `education/exams.js`: 교육학 기출 PDF에서 추출한 텍스트
- `education/README_교육학_패치.md`: 이 설명서

PDF를 그대로 보여주는 기능은 없으며, 패치 압축파일 안에도 원본 PDF는 포함되지 않습니다.

## 검증 메모

- Node `--check`로 신규/수정 JS 구문 검사.
- 원래 프로젝트의 `validate:behavior` 및 `validate:ux` 검사 통과.
- 기존 `validate:package`는 `exam-data.js`의 과거 고정 쿼리 문자열을 요구하는 검사여서 현 프로젝트 버전과 불일치하여 실패함. 교육학 패치의 자원 누락을 뜻하지는 않음.
- 실행 브라우저 자동화는 이 실행 환경의 로컬 탐색 제한으로 완료하지 못함. 실제 배포 환경의 클릭·저장·복원 검증이 추가로 필요합니다.


## v2 보완 사항

- 실수로 중복 추가되었던 9개 개념을 제거하여 **58개 개념 / 78개 질문**으로 정리했습니다. 기존 30개 문항 ID는 그대로 유지합니다.
- 답안을 작성한 후 정답의 **필수 표현 포함 여부**를 선택적으로 확인할 수 있습니다. 일치율은 **공식 채점이나 의미 기반 채점이 아닙니다.**
- 기출 자료 15쪽의 **학년도·쪽 정보**를 정리했습니다. 2014·2015학년도는 각각 2쪽이 포함되어 있습니다.
- 그림·도식이 포함된 필기 PDF는 직접 텍스트를 추출할 수 없습니다. 개념 텍스트는 사람이 판독해 재구성한 학습용 요약이며, **23쪽 전부의 완전 전사로 표시하지 않습니다.**
- `교육학 기출` 원문 문제와 사이트 자체 제작 연습문제를 구분합니다.


## v3 필기 자료 보강

- **58개 개념, 78개 가변형 서술 질문**으로 확장했습니다. 기존 30개 개념과 질문 ID는 유지합니다.
- 이미지 형태의 필기 PDF 23쪽을 직접 확인하고, 23쪽 모두에서 판독 가능한 주제를 최소 1개 이상 텍스트로 정리했습니다. 다만 이는 **모든 문장·소항목에 대한 완전한 전사가 아닙니다.**
- 새로 정리한 범위: 학습 전이·관찰학습·학습동기·인지양식·지능·창의성·교육과정 유형 및 운영·수업설계·교수법·평가관·평가 참조 방식·형성평가·자기/동료평가 등.
- 필기 원문 23쪽의 학교운영위원회 구성 비율은 적용 법령의 시점과 학교 유형에 따라 달라질 수 있어 **현행 법적 기준으로 검증하지 않은 원문 메모**로 표시합니다.
- 기출 PDF 전체 15쪽은 텍스트로 포함했으나 각 기출의 공식 채점요소·모범논술 답안은 현재 제공된 PDF에 포함되지 않아 자동 생성하지 않았습니다.


## v4 기출 답안 훈련 보강

- **기출 논제 분석 메모**를 문제지 페이지별로 저장합니다. 이 메모는 사용자 직접 작성이며 자동 정답이나 공식 채점 기준이 아닙니다.
- **기출 답안 자기 평정**(재학습 1일 / 부분 서술 3일 / 요구사항 충족 7일 / 숙지 14일)을 추가했습니다. 학습 이력이 개념형 질문과 분리되어 저장됩니다.
- **오답·복습 → 기출 재풀이**에서 취약하거나 복습일이 도래한 기출 페이지로 이동할 수 있습니다.
- 기존 `curriloop:education:text:v1` 기록 및 v1 백업 JSON 형식을 유지합니다. v3에 없는 새 필드만 추가하여 구버전 기록을 불러올 수 있도록 했습니다.
- 기출은 원본 PDF 페이지 기준 15개 항목입니다. 연도별 문항 분리 및 공신력 있는 채점 기준 검증은 미완료 상태입니다.
